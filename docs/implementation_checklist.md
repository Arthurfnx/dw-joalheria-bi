# Checklist de implementação

- [ ] Inspecionar repositório e `git status`.
- [ ] Disponibilizar localmente as fontes reais em `data/raw/`.
- [ ] Inventariar arquivos, abas, colunas, tipos, linhas e datas.
- [ ] Confirmar granularidade e unidades com o parceiro.
- [ ] Confirmar semântica de custo de compra e preço de venda.
- [ ] Verificar período e completude do histórico.
- [ ] Definir modelo dimensional baseado nas evidências.
- [ ] Preparar PostgreSQL local.
- [ ] Criar staging e auditoria.
- [ ] Implementar ETL e testes de qualidade.
- [ ] Implementar fatos/dimensões aprovadas.
- [ ] Validar medidas e indicadores.
- [ ] Instalar Power BI Desktop.
- [ ] Conectar Power BI ao DW e validar relatórios.
